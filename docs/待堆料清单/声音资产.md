## 待办项目

| 资源             | 用途                | 路径                            | 优先级 | 备注                               |
| ---------------- | ------------------- | ------------------------------- | ------ | ---------------------------------- |
| `sfx_throw.wav`  | 抛射/甩出宠物时触发 | `transparent-pet/assets/audio/` | 中     | 短音效 < 0.5s                      |
| `sfx_pickup.wav` | 鼠标按住宠物时触发  | `transparent-pet/assets/audio/` | 中     | 点击感音效                         |
| `sfx_land.wav`   | 落地反弹时触发      | `transparent-pet/assets/audio/` | 中     | 轻响，需在 drag_controller.gd 接线 |
| `bgm_idle.ogg`   | 待机背景音乐        | `transparent-pet/assets/audio/` | 低     | 循环，可选                         |

## 如何接线

- `sfx_throw` 与 `sfx_pickup` 已在 `modules/pet/scripts/pet.gd` 的 `_input()` 中通过 `EventBus.publish("play_sound", ...)` 发出；真正的资源放入对应路径即可被 `core/services/audio_manager.gd` 自动播放
- `sfx_land`：当前尚未在 `drag_controller.gd` 中接线。建议在落地判定处追加 `EventBus.publish("play_sound", {"path": SFX_LAND})`
