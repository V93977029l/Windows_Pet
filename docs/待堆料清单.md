## 4. 宠物行为状态机（完全未开始）

当前宠物只有"拖动/抛射"两种输入驱动的行为。
可加入**被动行为**让宠物"活起来"：

| 行为                | 触发条件                 | 说明                  |
| ------------------- | ------------------------ | --------------------- |
| 闲逛 (idle_wander)  | 长时间无输入             | 在桌面随机小范围移动  |
| 打瞌睡 (idle_sleep) | 超长时间无输入           | 透明度渐低 + 呼吸减慢 |
| 被摸头 (pat_head)   | 鼠标悬停在宠物上而不拖动 | 短暂缩放动画          |
| 落地/弹起动画       | 物理落地事件             | 与 SFX_LAND 联动      |

**接入方式**：新建 `modules/behavior/`（或在 pet 中加 `scripts/behavior_*.gd`），通过 EventBus 订阅拖拽/释放事件并修改状态。
