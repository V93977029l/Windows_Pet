# TransparentPet 项目结构总览

这是一个 **Godot 4 桌面桌宠（Desktop Pet）项目**，名为 **TransparentPet**。核心功能是：一个小型桌面精灵角色，具有透明背景、鼠标穿透（仅在鼠标悬停时交互）、系统托盘控制、抛射物理效果等功能。项目采用 **商业级模块化架构**，并使用 **GDExtension**（C++ 原生扩展）与 Windows API 进行底层交互。

**职责：**

## 六、GDExtension 相关文件

### 6.1 鼠标穿透扩展 (mouse_passthrough_extension)

| 文件            | 路径                                                                    | 功能                     |
| --------------- | ----------------------------------------------------------------------- | ------------------------ |
| GDExtension配置 | `gdextension/mouse_passthrough_extension/mouse_passthrough.gdextension` | 定义入口符号             |
| 头文件          | `gdextension/mouse_passthrough_extension/src/mouse_passthrough.h`       | 类声明                   |
| 实现            | `gdextension/mouse_passthrough_extension/src/mouse_passthrough.cpp`     | Windows API 实现鼠标穿透 |
| 注册            | `gdextension/mouse_passthrough_extension/src/register_types.cpp`        | GDExtension 入口         |

### 6.2 系统托盘扩展 (system_tray_extension)

| 文件            | 路径                                                        | 功能                     |
| --------------- | ----------------------------------------------------------- | ------------------------ |
| GDExtension配置 | `gdextension/system_tray_extension/system_tray.gdextension` | 定义入口符号             |
| 头文件          | `gdextension/system_tray_extension/src/system_tray.h`       | 类声明                   |
| 实现            | `gdextension/system_tray_extension/src/system_tray.cpp`     | Windows API 实现系统托盘 |
| 注册            | `gdextension/system_tray_extension/src/register_types.cpp`  | GDExtension 入口         |

### 6.3 液态玻璃扩展 (liquid_glass_extension)

| 文件    | 路径                                                      | 功能         |
| ------- | --------------------------------------------------------- | ------------ |
| 头文件  | `gdextension/liquid_glass_extension/src/liquid_glass.h`   | 类声明       |
| 实现    | `gdextension/liquid_glass_extension/src/liquid_glass.cpp` | 液态玻璃效果 |
| SDF工具 | `gdextension/liquid_glass_extension/src/sdf_utils.*`      | SDF计算工具  |

### 6.4 编译脚本

`gdextension/build.py` - 一键编译脚本，流程：
1. 验证 godot-cpp 完整性
2. 编译 godot-cpp
3. 编译各扩展
4. 部署 DLL + .gdextension 到 `transparent-pet/addons/`

## 八、模块化架构设计原则

### 8.1 核心原则

1. **按功能组织，非按类型**
   - `modules/pet/` 包含 pet 的所有文件（场景、脚本、资源）
   - 而非 `scenes/`, `scripts/`, `assets/` 分离

2. **接口契约 (api.gd)**
   - 每个模块都有 `api.gd` 定义公共接口
   - 外部模块只能通过 api 交互
   - 内部实现细节完全隐藏

3. **信号优先**
   - 模块间通信优先使用信号
   - 避免直接引用其他模块的内部类

4. **core/ 稳定原则**
   - core/ 目录下的代码应高度稳定
   - 修改 core/ 需谨慎

### 8.2 模块间通信示例

```gdscript
# 设置窗口 -> 宠物模块（通过 API）
pet_node.update_pet_scale(1.5)

# 宠物模块 -> 其他模块（通过信号）
pet_node.pet_scale_changed.connect(_on_scale_changed)
```
