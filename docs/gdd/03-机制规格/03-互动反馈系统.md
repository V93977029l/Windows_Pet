# 机制规格 — 互动反馈系统 (Interaction Feedback)

> **所属 GDD**：TransparentPet / 03-机制规格 | **状态**：v0.1.0-draft
> **设计支柱**：支柱 2（即时把玩手感）—— 本系统是支柱 2 的**核心载体**
> **依赖**：情绪系统（互动改变情绪）、自主行为系统（互动打断行为）、显示模块（形变/材质反馈）

---

## 1. 机制目的 (Purpose)

让玩家与宠物的每次接触都有**即时、可感知、满足**的反馈，使拖拽/抛射/点击成为工作中的解压出口。

**这是项目已有的技术优势**——抛射物理、液态玻璃形变已实现。本系统的任务是**规格化手感**，确保反馈一致且持续打磨。

## 2. 玩家幻想 (Player Fantasy)

_"它跟手，扔出去有重量感，落地弹起来真解压。我烦躁的时候就想拖它一下。"_

玩家应感觉到：

- 拖拽跟手无延迟，像拖一个有质量的真实物体
- 抛射有惯性，飞行轨迹符合物理直觉
- 落地有弹性，弹跳衰减自然
- 接触瞬间有形变反馈（挤压、拉伸），体现"软"的质感
- 反馈是多通道的（视觉形变 + 表情 + 音效）

## 3. 互动类型与规格

### 3.1 拖拽 (Drag) — 已实现，需规格化手感

| 维度     | 规格                                     | 现状       |
| -------- | ---------------------------------------- | ---------- |
| 触发     | 鼠标左键按下宠物实体（像素级检测）       | ✅ 已实现  |
| 跟手延迟 | ≤ `[P]` 16ms（一帧）                     | 待验证     |
| 跟手模式 | 直接跟随（无弹簧/阻尼），保证零延迟感    | 现状待确认 |
| 形变反馈 | 拖拽方向反向拉伸（惯性形变），体现质量感 | 部分实现   |
| 情绪影响 | 轻柔拖：+愉悦+亲密；粗暴拖：-愉悦+活力   | 待实现     |

**手感调优重点**：

- 拖拽时宠物应**轻微滞后于鼠标**（弹性跟手），而非死贴鼠标——前者有"质量感"，后者像拖空图标
- 但滞后必须极小（`[P]` ms 级），否则像延迟 bug

### 3.2 抛射 (Throw) — 已实现

| 维度     | 规格                                             | 现状          |
| -------- | ------------------------------------------------ | ------------- |
| 触发     | 拖拽中松手，且松手速度 > 最小触发速度            | ✅ 已实现     |
| 物理参数 | 重力、初速度、最大速度、速度放大系数（均可配置） | ✅ 已实现配置 |
| 边界碰撞 | 屏幕边缘弹性反弹                                 | ✅ 已实现     |
| 地面摩擦 | 落地后减速至停止                                 | ✅ 已实现     |
| 飞行形变 | 飞行中拉伸（运动方向）、落地挤压（法线方向）     | 待实现        |
| 弹跳音效 | 每次弹跳轻柔音效（默认关，可开）                 | 待实现        |

**手感调优重点**：

- 抛射初速度映射要**有冲量感**——小幅拖拽不该飞太远，大幅甩动才飞得远
- 弹跳次数 `[P]` 2-4 次后停止，太多显得轻飘，太少显得死沉
- 落地挤压形变是"解压感"的关键来源，需重点打磨

### 3.3 点击 (Click) — 待规格化

| 维度     | 规格                                                      |
| -------- | --------------------------------------------------------- |
| 触发     | 鼠标左键单击宠物实体（非拖拽）                            |
| 反馈     | 局部形变（被点位置凹陷）+ 表情反馈（惊讶→开心）+ 轻微弹起 |
| 情绪影响 | +愉悦 +活力 +亲密                                         |
| 冷却     | `[P]` 0.3s（防连点 spam）                                 |
| 失败态   | 连点无额外反馈（避免鼓励 spam 互动）                      |

### 3.4 观看 (Watch) — 待实现

| 维度     | 规格                                            |
| -------- | ----------------------------------------------- |
| 触发     | 玩家鼠标静止悬停宠物 ≥ `[P]` 1.5s               |
| 反馈     | 宠物转向鼠标，表现"被关注开心"（表情+小幅动作） |
| 情绪影响 | +愉悦 +亲密（被关注是正向）                     |
| 设计意图 | 奖励"陪伴式"轻互动，不只是操作式互动            |

### 3.5 捏/形变 (Squish) — 待实现，未来扩展

| 维度     | 规格                               |
| -------- | ---------------------------------- |
| 触发     | 右键按住拖动（或特定手势）         |
| 反馈     | 宠物局部形变跟随，像捏软糖         |
| 情绪影响 | 轻柔：+愉悦；过度：-愉悦（有保护） |
| 依赖     | 液态玻璃形变能力（已有原型）       |

## 4. 反馈通道矩阵

每次互动应通过**多通道**叠加反馈，强化"真实感"：

| 互动 | 视觉形变          | 表情      | 音效           | 情绪   |
| ---- | ----------------- | --------- | -------------- | ------ |
| 拖拽 | 惯性拉伸          | 专注/享受 | 无（默认）     | +亲密  |
| 抛射 | 飞行拉伸+落地挤压 | 兴奋/惊吓 | 弹跳声（可开） | +活力  |
| 点击 | 局部凹陷+弹起     | 惊讶→开心 | 啵声（可开）   | +愉悦  |
| 观看 | 转向鼠标          | 开心      | 无             | +亲密  |
| 捏   | 跟随形变          | 享受/抗拒 | 无             | 视强度 |

**原则**：音效默认关闭（避免工作打扰），玩家可在设置开启。视觉形变是主反馈通道。

## 5. 成功条件 (Success Condition)

| 验证项   | 标准                                 |
| -------- | ------------------------------------ |
| 跟手     | 玩家感觉拖拽"无延迟"（实际 ≤16ms）   |
| 重量感   | 玩家描述宠物"有分量"而非"轻飘飘"     |
| 解压感   | 玩家在烦躁时会主动抛射宠物发泄       |
| 反馈一致 | 同一互动的反馈每次一致（不随机跳变） |
| 可中断   | 任何互动可被新互动打断，不卡死       |

## 6. 失败状态 (Failure State)

| 失败   | 表现       | 根因              | 修复方向           |
| ------ | ---------- | ----------------- | ------------------ |
| 延迟感 | 拖拽跟手慢 | 渲染/输入管线延迟 | 优化输入到渲染路径 |
| 轻飘感 | 抛射无重量 | 重力/速度参数不当 | 调参 + 增加形变    |
| 死板   | 形变无变化 | 形变曲线僵硬      | 用缓动函数软化     |
| 打扰   | 互动音效吵 | 音效默认开        | 默认静音           |
| 卡顿   | 互动中掉帧 | 物理计算重        | 优化物理或降频     |

## 7. 边界情况 (Edge Cases)

| 情况               | 处理                                   |
| ------------------ | -------------------------------------- |
| 拖拽出屏幕边缘     | 限制在可视桌面范围内（不跑屏外找不到） |
| 极速拖拽（甩动）   | 速度有上限（已实现），避免飞太远       |
| 拖拽中宠物进入睡眠 | 拖拽唤醒，打断睡眠                     |
| 多次快速点击       | 冷却期内只触发首次，避免 spam          |
| 抛射中再次点击     | 飞行物理优先，点击忽略至落地           |
| 窗口最小化时互动   | 不可互动（托盘恢复窗口后才可）         |

## 8. 调优杠杆

详见 [05-调优变量表.md](../05-调优变量表.md)：

| 杠杆             | 假设值               | 调优目的         |
| ---------------- | -------------------- | ---------------- |
| 拖拽跟手弹性系数 | `[P]`                | 质量感 vs 延迟感 |
| 抛射重力         | `[P]` 100-3000 px/s² | 重量感           |
| 抛射速度上限     | `[P]`                | 防飞太远         |
| 弹跳衰减系数     | `[P]`                | 弹跳次数         |
| 落地挤压形变量   | `[P]`                | 解压感强度       |
| 点击冷却         | `[P]` 0.3s           | 防 spam          |
| 观看触发悬停时长 | `[P]` 1.5s           | 误触 vs 真观看   |

## 9. 依赖关系

| 依赖方向           | 说明                     |
| ------------------ | ------------------------ |
| → 情绪系统         | 互动事件触发情绪变化     |
| → 自主行为系统     | 互动打断当前行为         |
| ← 显示模块（工程） | 形变需驱动精灵/着色器    |
| ← 物理模块（工程） | 抛射依赖物理引擎（已有） |
| → 音频系统（待建） | 部分互动需音效           |

## 10. 实现备注

- 已实现的拖拽/抛射物理**保留**，本系统在其上补充形变反馈与情绪联动
- 形变反馈通过现有的液态玻璃着色器能力实现（已有原型）
- 互动事件应统一入口（已有 DragController），新增点击/观看通过事件扩展

## 11. 待验证假设

3. 落地挤压形变量——多少算"解压"，多少算"夸张"
4. 音效默认开关对打扰感的影响
