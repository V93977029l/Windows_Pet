# 机制规格 — 情绪系统 (Emotion System)

> **所属 GDD**：TransparentPet / 03-机制规格 | **状态**：v0.1.0-draft
> **设计支柱**：支柱 1（陪伴在场感）—— 情绪让宠物"有内心"
> **依赖**：自主行为系统（情绪驱动行为）、互动反馈系统（互动改变情绪）

---

## 1. 机制目的 (Purpose)

让宠物有"心情"，使玩家感觉互动有累积意义、宠物"记得"被对待的方式。

**没有情绪系统，互动就是一次性消耗**——拖十次和拖一次体感无差，无法建立情感连接。

## 2. 玩家幻想 (Player Fantasy)

_"我几天没理它，它有点低落；我陪它玩了一会儿，它又开心了。它好像真的有情绪。"_

玩家应感觉到：

- 互动会改变宠物的心情
- 心情会自然衰减/恢复（不是永久状态）
- 心情影响宠物的行为表现（开心时爱动，低落时发呆）
- 不互动会有"它想我了"的反馈（但不焦虑、不惩罚）

## 3. 反对动机红线（重要）

> **绝不引入焦虑感**：宠物情绪**不会"死"、不会"生病"、不会因低落而永久损坏**。低情绪只是表现变化，玩家随时可以恢复。这是桌宠品类的底线——我们是放松产品，不是养成惩罚游戏。

## 4. 输入 / 输出

| 类型         | 输入                                                                | 输出 |
| ------------ | ------------------------------------------------------------------- | ---- |
| 情绪变化输入 | 玩家互动（拖/抛/点击/观看）、时间流逝（衰减）、特殊事件（开机迎接） | —    |
| 输出         | 当前情绪值（多维）、情绪表现（表情/颜色/行为偏置）                  | —    |

## 5. 情绪模型

采用**多维情绪轴**而非离散状态机。多维模型更细腻，且天然支持混合情绪。

### 5.1 情绪维度

| 维度          | 范围  | 含义         | 低端表现       | 高端表现     |
| ------------- | ----- | ------------ | -------------- | ------------ |
| 愉悦度 (Joy)  | 0-100 | 开心程度     | 低落、发呆多   | 活跃、爱玩   |
| 活力 (Energy) | 0-100 | 精力         | 困倦、想睡     | 好动、爱动   |
| 亲密度 (Bond) | 0-100 | 与玩家的连接 | 冷淡、不看玩家 | 黏人、求互动 |

**为何不用"饥饿/无聊"等需求型维度**：需求型会引入"必须满足"的压力（违背反对动机），且桌宠无死亡机制时需求无意义。本模型是纯表现型，不产生玩家义务。

### 5.2 情绪触发器

| 触发                | 愉悦度    | 活力      | 亲密度    | 说明               |
| ------------------- | --------- | --------- | --------- | ------------------ |
| 被拖拽（轻柔）      | +`[P]`    | -`[P]`    | +`[P]`    | 适度互动           |
| 被拖拽（粗暴/快速） | -`[P]`    | +`[P]`    | ±0        | 过猛可能不喜欢     |
| 被抛射              | -`[P]` 小 | +`[P]`    | ±0        | 有惊吓感但不强惩罚 |
| 被点击              | +`[P]`    | +`[P]`    | +`[P]`    | 正向关注           |
| 被长时间观看        | +`[P]`    | ±0        | +`[P]`    | 被关注开心         |
| 玩家长时间无互动    | -`[P]` 慢 | -`[P]` 慢 | -`[P]` 慢 | 自然衰减，不惩罚   |
| 开机/启动迎接       | +`[P]`    | +`[P]`    | +`[P]`    | 每日仪式感         |
| 解锁新内容          | +`[P]`    | +`[P]`    | ±0        | 惊喜               |

`[P]` = `[PLACEHOLDER]`，详见调优表。

### 5.3 情绪衰减与恢复

| 维度   | 自然趋势             | 速率                                       |
| ------ | -------------------- | ------------------------------------------ |
| 愉悦度 | 向中值 50 回归       | `[P]` /min                                 |
| 活力   | 随时间下降，睡眠恢复 | `[P]` /min 下降，睡眠时 `[P]` /min 恢复    |
| 亲密度 | 缓慢下降（不互动时） | `[P]` /min（比愉悦度慢，体现"关系"持久性） |

**关键设计**：愉悦度向中值回归（不互动也不会一直低落），避免玩家"被迫"互动。亲密度缓慢下降但可快速通过互动恢复，体现"关系需要维护但不苛刻"。

## 6. 情绪表现映射

情绪通过**多个可见通道**叠加表现，让玩家"读"出来：

| 情绪区间 | 表情        | 颜色/材质        | 行为偏置       |
| -------- | ----------- | ---------------- | -------------- |
| 愉悦度高 | 笑眼/弯嘴   | 偏暖色调、高光强 | 爱玩耍、散步   |
| 愉悦度低 | 无神眼/直嘴 | 偏冷色调、高光弱 | 多发呆、睡眠   |
| 活力低   | 半闭眼      | 略暗             | 进入睡眠倾向   |
| 亲密度高 | 看玩家频繁  | —                | Watch/求互动多 |
| 亲密度低 | 不看玩家    | —                | 自顾自发呆     |

**表现原则**：情绪表现要**渐进**而非跳变——愉悦度从 60 到 40 不应突然变脸，而是逐渐"没那么有精神"。

## 7. 成功条件 (Success Condition)

| 验证项 | 标准                                   |
| ------ | -------------------------------------- |
| 可感知 | 玩家能说出"它现在心情好像不太好"       |
| 可影响 | 玩家知道"我陪它玩它就开心了"           |
| 无焦虑 | 玩家不会因宠物低落而感到"我失职了"     |
| 连续性 | 跨会话玩家感觉"它还记得我昨天陪它玩了" |

## 8. 失败状态 (Failure State)

| 失败     | 表现                   | 根因                    | 修复方向               |
| -------- | ---------------------- | ----------------------- | ---------------------- |
| 不可感知 | 玩家觉得情绪没变化     | 表现差异太弱            | 强化表情/颜色差异      |
| 焦虑感   | 玩家觉得"必须陪它"     | 衰减太快/低落表现太强烈 | 减缓衰减、弱化低落视觉 |
| 无意义   | 玩家觉得情绪不影响什么 | 情绪与行为脱钩          | 强化情绪对行为的偏置   |
| 卡死     | 情绪数值异常           | 触发器 bug、边界溢出    | 数值钳制 + 日志        |

## 9. 边界情况 (Edge Cases)

| 情况                        | 处理                                                         |
| --------------------------- | ------------------------------------------------------------ |
| 玩家粗暴拖拽很久            | 愉悦度有下限保护（不会到 0），避免"虐待"体验                 |
| 玩家长时间离开（关机/出差） | 情绪不无限衰减，回归中值后稳定；回来时亲密度略低但可快速恢复 |
| 情绪多触发器同时作用        | 数值累加后统一钳制到 0-100                                   |
| 解锁新内容瞬间              | 临时提升愉悦度，制造"它也开心"的共情                         |
| 玩家从未互动（纯挂着）      | 情绪维持中值附近，宠物正常自主活动，不表现"被冷落"的强烈信号 |

## 11. 依赖关系

| 依赖方向           | 说明                       |
| ------------------ | -------------------------- |
| → 自主行为系统     | 输出情绪值作为行为选择输入 |
| ← 互动反馈系统     | 接收互动事件作为情绪触发器 |
| → 显示模块（工程） | 情绪表现需驱动表情/材质    |
| → 收集解锁系统     | 解锁事件触发情绪正向变化   |

## 12. 实现备注

- 情绪状态需持久化（关机重启后不重置），但衰减在关机期间不计算（不惩罚离线）
- 情绪数值变化应平滑插值（lerp），避免表现跳变
- 情绪触发器应事件化，便于新增触发源不改核心逻辑

## 13. 待验证假设

1. 愉悦度回归中值的速率——太慢则低落持续太久，太快则互动无累积感
2. 亲密度衰减是否让玩家感到"必须维护"（反对动机红线）
3. 粗暴拖拽是否应惩罚（可能让玩家不敢抛射，违背支柱 2）
4. 情绪表现差异阈值——玩家实际能分辨多少数值差
