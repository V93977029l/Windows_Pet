# 04 — 成就与收集册系统

> **所属 GDD**：TransparentPet | **状态**：v0.1.0-draft
> **设计支柱**：支柱 3（收集驱动好奇）
> **经济模型**：无货币，本系统是唯一的长期进度载体
> **关联**：[03-机制规格/04-收集解锁系统.md](03-机制规格/04-收集解锁系统.md)（解锁来源）

---

## 设计目标

在**无货币经济**前提下，提供长期目标与回头理由。所有解锁通过成就达成，不设计商店、不设计付费跳过、不设计每日任务。

**核心原则**：成就应**自然达成**于正常游玩，而非"要求玩家去做某事"。玩家不应感觉"在刷成就"。

---

## 一、成就体系结构

成就分四类，按"达成方式"组织：

| 类型       | 达成方式          | 玩家感受             | 占比 |
| ---------- | ----------------- | -------------------- | ---- |
| 里程碑成就 | 累计数值自然达到  | "我已经陪它这么久了" | 40%  |
| 行为成就   | 自然互动中触发    | "原来还能这样玩"     | 25%  |
| 时长成就   | 在线时长累计      | "它陪我工作很久了"   | 20%  |
| 探索成就   | 发现隐藏/特殊条件 | "居然还有这个"       | 15%  |

**不做**：每日任务、签到、限时挑战（违背"无负担"红线）。

## 三、收集册 (Collection Book)

收集册是玩家回顾成果、查看进度的载体。

### 3.1 收集册结构

```
收集册
├── 皮肤图鉴（已拥有/未拥有灰显/隐藏???）
├── 表情图鉴
├── 行为图鉴
├── 道具图鉴
├── 称号列表
└── 成就墙（已达成成就展示）
```

### 3.2 收集册交互

| 功能       | 说明                                               |
| ---------- | -------------------------------------------------- |
| 查看       | 点击已拥有内容查看预览/演示                        |
| 装备       | 皮肤/表情/行为可直接从收集册装备（联动自定义系统） |
| 进度       | 每类显示 "已拥有 X / 总 Y" + 进度条                |
| 隐藏内容   | 未发现的显示 ???，发现后点亮                       |
| 稀有度标记 | 普通/稀有/传说 三档，视觉区分                      |

### 3.3 收集册入口

| 入口       | 触发                         |
| ---------- | ---------------------------- |
| 设置窗口   | 设置内"收集册"页签           |
| 托盘菜单   | 右键托盘 → "收集册"          |
| 解锁后提示 | 解锁瞬间提示"可在收集册查看" |

## 四、解锁节奏曲线（汇总）

来自 [03-机制规格/04-收集解锁系统.md](03-机制规格/04-收集解锁系统.md) 第 6 节：

| 阶段 | 累计可解锁数     | 节奏                  |
| ---- | ---------------- | --------------------- |
| 首日 | `[P]` 3-5        | 密集，建立认知        |
| 首周 | `[P]` 8-12       | 每天 1-2 个，维持新鲜 |
| 首月 | `[P]` 20-25      | 每 3-5 天 1 个        |

**总内容量目标**：`[P]` 50-70 个可解锁内容，支撑 `[P]` 2-3 个月活跃游玩。

## 五、无货币经济的留存论证

为何"仅成就/收集册"足以支撑留存：

| 留存驱动 | 传统货币经济   | 本方案（成就/收集册） |
| -------- | -------------- | --------------------- |
| 短期目标 | 攒钱买下一个   | 下个成就达成          |
| 长期目标 | 攒钱买稀有     | 集齐收集册            |
| 进度可见 | 货币余额       | 收集册进度条          |
| 回头理由 | 怕错过每日收入 | 想推进下个成就        |

**优势**：

- 无"货币通胀"风险（货币经济需平衡产出/消耗）
- 无"付费跳过"破坏成就感
- 无"每日任务"肝感

**风险**：

- 成就达完后无目标（需持续更新内容 / 季节性成就）
- 无货币消费出口，玩家可能觉得"没花处"（但桌宠本就该轻量）

**缓解**：发售后持续更新成就包（免费）+ DLC 皮肤包（付费）。

## 六、成功条件

| 验证项   | 标准                                         |
| -------- | -------------------------------------------- |
| 进度可见 | 玩家随时知道"还差多少"                       |
| 自然达成 | > 80% 成就在正常游玩中达成，非刻意刷         |
| 回头驱动 | 次日留存 > `[P]` 50%，周留存 > `[P]` 30%     |
| 无肝感   | 玩家调查中"肝"相关负面反馈 < `[P]` 10%       |
| 集齐满足 | 集齐收集册的玩家有强烈成就感（非"终于解脱"） |

---

## 七、待验证假设

1. 首周 8-12 个解锁是否合适
2. 隐藏成就占比 15% 是否引发探索欲而非挫败
3. 无货币经济是否足以支撑 2-3 月留存
4. 成就达成后的"空窗期"如何缓解（季节性更新节奏）
