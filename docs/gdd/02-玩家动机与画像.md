## 设计目标

## 一、目标玩家画像

桌宠用户不是单一人群。基于桌宠品类用户研究（参考 Shimeji、桌宠类 Steam 产品的评价与社区），定义三个核心画像：

### 画像 A — "陪伴型"打工人

| 维度     | 描述                                                          |
| -------- | ------------------------------------------------------------- |
| 年龄     | 22-32                                                         |
| 场景     | 长时间独处电脑前工作（程序员、设计、文字工作者、学生）        |
| 痛点     | 工作枯燥孤独，想要"有个活物陪着"但不养真宠物（麻烦/租房禁养） |
| 动机     | **陪伴感**：感觉被陪伴、不孤独                                |
| 期望     | 宠物有自主行为和情绪，像真的一样"活着"                        |
| 反感     | 打扰工作、抢焦点、强制互动                                    |
| 付费意愿 | 中（愿为高质量陪伴体验买断）                                  |
| 支柱对应 | **支柱 1（陪伴在场感）为主**                                  |

### 画像 B — "解压型"摸鱼人

| 维度     | 描述                                               |
| -------- | -------------------------------------------------- |
| 年龄     | 18-28                                              |
| 场景     | 工作/学习间隙想放松，会刷手机、玩小程序游戏        |
| 痛点     | 想要即时的小解压，但不想开大型游戏、不想投入注意力 |
| 动机     | **解压**：即时手感反馈，发泄式互动（拖、抛、捏）   |
| 期望     | 互动手感爽快，物理反馈真实，视觉/音效满足          |
| 反感     | 互动有延迟、反馈弱、需要思考                       |
| 付费意愿 | 低-中（手感好才买，否则弃用）                      |
| 支柱对应 | **支柱 2（即时把玩手感）为主**                     |

### 画像 C — "收集型"养成控

| 维度     | 描述                                                         |
| -------- | ------------------------------------------------------------ |
| 年龄     | 16-30                                                        |
| 场景     | 喜欢"集齐""解锁"的成就感，玩过猫咪后院、旅行青蛙、收集类手游 |
| 痛点     | 想要长期目标和收集进度，但反感重肝和付费墙                   |
| 动机     | **收集完成感**：集齐皮肤/表情/场景，有可炫耀的成果           |
| 期望     | 收集进度清晰、解锁有仪式感、收集册可展示                     |
| 反感     | 每日任务强制、断签惩罚、靠挂机/付费解锁                      |
| 付费意愿 | 中-高（愿为稀有/限定内容付费，但拒绝 pay-to-skip）           |
| 支柱对应 | **支柱 3（收集驱动好奇）为主**                               |

## 二、混合型定位下的主次排序论证

TransparentPet 选择混合型，意味着三个画像都要服务。但资源有限，必须排主次。

### GameDesigner 建议排序（待项目负责人确认）

| 排序 | 画像             | 支柱   | 权重    | 论证                                                                                       |
| ---- | ---------------- | ------ | ------- | ------------------------------------------------------------------------------------------ |
| 1    | 画像 A（陪伴型） | 支柱 1 | **40%** | 桌宠品类的**核心人群**，也是留存最稳的人群。他们留下来的理由是"陪伴"，不是"好玩"。         |
| 2    | 画像 B（解压型） | 支柱 2 | **35%** | 项目**已有技术优势**（抛射物理、液态玻璃形变），且解压是高频即时需求，转化快。             |
| 3    | 画像 C（收集型） | 支柱 3 | **25%** | 提供**长期留存与付费点**，但收集型用户对桌宠品类忠诚度低于前两者，且过度收集会反噬陪伴感。 |

### 排序的实践含义

| 决策类型       | 排序带来的取舍                                                                 |
| -------------- | ------------------------------------------------------------------------------ |
| 资源分配       | 自主行为 + 情绪系统投入 > 把玩手感打磨 > 收集内容量                            |
| 冲突仲裁       | 当"收集压力"与"陪伴不打扰"冲突时，**陪伴优先**（不做每日任务、不强制互动解锁） |
| Steam 商店定位 | 主宣传点应是"会陪伴你的桌面宠物"，而非"收集 100 种皮肤"                        |
| MVP 优先级     | 先做支柱 1+2 的最小闭环，支柱 3 可延后                                         |

## 三、核心动机（我们要满足的）

| 动机 | 描述                   | 服务画像 | 支柱 |
| ---- | ---------------------- | -------- | ---- |
| 陪伴 | 感觉被陪伴，不孤独     | A        | 1    |
| 解压 | 即时发泄，缓解压力     | B        | 2    |
| 掌控 | 拖拽/抛射时"它听我的"  | B        | 2    |
| 好奇 | 想看它下次会做什么     | A、C     | 1、3 |
| 收集 | 集齐全体的完成感       | C        | 3    |
| 表达 | 用皮肤/自定义彰显个性  | A、C     | 3    |
| 仪式 | 每日开关机有固定小仪式 | A        | 1    |

## 四、反对动机（我们坚决不做的）

> 反对动机是**红线**。任何设计若触发以下体验，即便能提升某项数据也拒绝。

| 反对动机         | 描述                           | 为什么拒绝                                        | 影响章节     |
| ---------------- | ------------------------------ | ------------------------------------------------- | ------------ |
| **打扰感**       | 宠物抢焦点、弹窗、强制交互     | 破坏"陪伴不打扰"核心契约，玩家会直接卸载          | 自主行为系统 |
| **肝感**         | 每日任务、断签惩罚、重复刷     | 桌宠不是手游，肝感直接驱逐画像 A、B               | 成就与收集册 |
| **付费墙**       | 核心体验被锁在付费后           | 陪伴感是基础体验，不应付费解锁；仅外观/限定可付费 | 收集解锁系统 |
| **焦虑感**       | 宠物会"死"、会"生病"、有倒计时 | 桌宠是放松产品，引入焦虑违背品类本质              | 情绪系统     |
| **无意义复杂度** | 为增加系统而增加系统           | 不产生有意义选择的系统是负担                      | 全部         |

## 五、竞品参考与差异化

| 竞品                   | 强项               | 弱项                              | TransparentPet 的差异化机会        |
| ---------------------- | ------------------ | --------------------------------- | ---------------------------------- |
| Shimeji                | 行为丰富、社区生态 | 画面粗糙、Java 重、Windows 兼容差 | Godot 原生、液态玻璃质感、现代视觉 |
| 桌面宠物（Steam 同类） | 多为 Live2D 立绘   | 多为静态展示，无物理交互          | 抛射物理 + 形变反馈，互动手感强    |
| 旅行青蛙               | 陪伴仪式感强       | 非桌面常驻                        | 桌面常驻 + 类似仪式感              |
| 猫咪后院               | 收集驱动清晰       | 非桌面、需主动打开                | 桌面被动在场 + 轻收集              |

**差异化定位一句话**：_"用现代视觉和真实物理手感，做一款会陪伴你工作的桌面宠物，而不是桌面贴图。"_

## 六、待验证假设

1. 三个画像的实际占比（需 Steam 发售后数据验证，现阶段假设 A:B:C = 4:3:3）
2. 画像 A 是否真能为"陪伴"付费（vs 认为陪伴应免费）
3. 画像 C 对"无付费墙收集"的接受度（是否反而觉得"没价值"）
4. 反对动机中哪一项是玩家最敏感的（playtest 时优先观察"打扰感"）
