# 06 — 新手引导流程 (Onboarding)

> **所属 GDD**：TransparentPet | **状态**：v0.1.0-draft
> **设计支柱关联**：服务全部三支柱的首次建立

---

## 设计目标

桌宠的 onboarding 不是传统游戏的"教程关卡"——它没有明确开始与结束。目标是：**玩家启动后 60 秒内理解宠物是什么、能做什么、且建立"明天还会开"的期待**。

**核心原则**：

- 不用文字墙——桌宠用户耐心低，文字教程直接劝退
- 用"发现"代替"告知"——让玩家自己摸到核心动词
- 首次体验必须有正向反馈——不能让玩家"不知道能干嘛"

---

## 一、首次启动体验流程

```
启动 → 宠物出现在桌面默认位置（屏幕底部居中，不挡视野）
  │
  │  ① 出场动画（`[P]` 1-2s）
  │     宠物以"苏醒/出现"动画进场（如从透明渐显 + 伸懒腰）
  │     配合轻柔音效（默认关，可开）
  │
  ▼
宠物开始自主行为（发呆/散步）
  │
  │  ② 引导发现拖拽（`[P]` 5s 后，若玩家未互动）
  │     宠物轻微"跳动"或"看向鼠标"吸引注意
  │     不弹文字提示，只用动作暗示"我可以被碰"
  │
  ▼
玩家尝试拖拽（预期行为）
  │
  │  ③ 拖拽即时反馈
  │     跟手 + 形变 + 情绪 +愉悦
  │     建立"拖它有反应"的核心认知（支柱 2）
  │
  ▼
玩家尝试抛射（自然延伸）
  │
  │  ④ 抛射物理反馈
  │     飞行 + 弹跳 + 落地挤压
  │     建立"扔它真解压"的解压认知（支柱 2）
  │
  ▼
自主行为持续（宠物开始散步/发呆/看玩家）
  │
  │  ⑤ 陪伴感建立
  │     玩家观察到"它在自己活动"
  │     建立"它是活的"认知（支柱 1）
  │
  ▼
约 `[P]` 2-5 分钟后，触发首个解锁
  │
  │  ⑥ 首个成就解锁
  │     如"初次见面"或"第一次抛射"
  │     解锁仪式感 + 收集册提示
  │     建立"有东西可收集"认知（支柱 3）
  │
  ▼
首次会话结束（玩家关机/最小化）
  │
  │  ⑦ 离开仪式
  │     宠物表现"告别"（挥手/睡眠）
  │     建立"明天再来看它"的回头预期
```

---

## 二、Onboarding Checklist

参考 GameDesigner 标准清单，逐项对照：

- [x] **核心动词 30 秒内可用**：拖拽（启动后立即可拖，无需解锁）
- [x] **首次成功保证**：首次拖拽必然成功（无失败可能）
- [x] **新机制在安全场景引入**：抛射无惩罚（落地不扣血、不损坏）
- [x] **至少一个机制靠探索发现**：观看触发情绪（无文字提示，玩家悬停偶然发现）
- [x] **首会话以 hook 结束**：首个解锁 + 离别仪式 = "明天再看"
- [x] **无强制教程**：全程无弹窗、无箭头、无"点击这里"
- [x] **无失败惩罚**：任何操作不产生负面后果

## 三、引导设计细节

### 3.1 出场动画

| 维度 | 规格                                              |
| ---- | ------------------------------------------------- |
| 时长 | `[P]` 1-2s                                        |
| 效果 | 透明度 0→100 渐显 + 伸懒腰形变 + 睁眼             |
| 情绪 | 起始愉悦度设为 70（略高于中值，"它见到你很开心"） |
| 音效 | 轻柔"醒来"音（默认关）                            |
| 重复 | 仅首次启动；后续启动用"迎接"动画（区别于首次）    |

### 3.2 注意引导（无文字）

玩家若 `[P]` 5s 未互动，宠物用**动作**而非文字吸引：

| 动作                 | 效果           |
| -------------------- | -------------- |
| 轻微跳动             | "我在这里"     |
| 看向鼠标             | "我注意到你了" |
| 靠近鼠标方向小幅移动 | "来碰我呀"     |

**反对**：弹"试试拖动我！"的文字气泡——破坏沉浸、显得廉价。

### 3.3 首个解锁设计

首个解锁应在 `[P]` 2-5 分钟内触发，且**无需刻意操作**：

| 候选         | 触发        | 奖励            |
| ------------ | ----------- | --------------- |
| "初次见面"   | 启动即达成  | 默认皮肤 + 称号 |
| "第一次抛射" | 首次抛射    | 惊讶表情包      |
| "第一次陪伴" | 在线 1 分钟 | 小枕头道具      |

**建议**："初次见面"启动即触发（保证 100% 首个解锁），建立收集册认知。

### 3.4 离开仪式

| 触发             | 反馈                                |
| ---------------- | ----------------------------------- |
| 玩家关机/退出    | 宠物挥手 + 渐隐                     |
| 玩家最小化到托盘 | 宠物"打哈欠" + 趴下（暗示它去睡了） |
| 玩家长时间空闲   | 宠物自行睡眠（不打扰）              |

**目的**：让"离开"也有仪式感，强化"它是个生命"的认知，建立"明天回来"的预期。

## 四、设置发现引导

玩家需知道**怎么打开设置**（调整缩放/材质/行为倾向等）：

| 引导方式   | 说明                                                     |
| ---------- | -------------------------------------------------------- |
| 托盘图标   | 右键托盘菜单明显可见"设置"                               |
| 快捷键提示 | 首次启动后，托盘 tooltip 提示"按 ` 键打开设置"（一次性） |
| 不强制     | 不弹窗要求玩家打开设置，设置是可选的                     |

**反对**：启动即弹设置窗口——打断首次体验，玩家还没玩就被要求配置。

---

## 五、反模式（绝对不做）

| 反模式                      | 为什么不做                     |
| --------------------------- | ------------------------------ |
| 启动弹"欢迎使用"文字        | 桌宠不需要欢迎，直接玩         |
| 强制教程步骤（1/5、2/5...） | 破坏自主探索，劝退             |
| 文字气泡"拖我！"            | 廉价感、打破沉浸               |
| 首次必须完成某操作才能继续  | 桌宠无"继续"概念，玩家随时可走 |
| 设置弹窗强制配置            | 首次应玩起来，配置是后续       |

## 六、成功条件

| 验证项         | 标准                                               |
| -------------- | -------------------------------------------------- |
| 核心动词发现率 | > `[P]` 90% 玩家在首分钟内尝试拖拽（无文字提示下） |
| 首个解锁达成率 | > `[P]` 95% 玩家在首会话触发首个解锁               |
| 次日留存       | > `[P]` 50%（onboarding 成功的关键指标）           |
| 无困惑反馈     | 玩家调查中"不知道能干嘛" < `[P]` 10%               |
| 无教程抱怨     | 玩家调查中"教程烦"相关反馈 = 0                     |

---

## 七、待验证假设

1. 5s 注意引导延迟是否合适（太早打扰、太晚流失）
2. 无文字提示下，拖拽发现率能否达 90%
3. 首个解锁"启动即达成"是否会让人觉得"太容易"
4. 离开仪式对次日留存的实际影响
