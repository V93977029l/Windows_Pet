# 05 — 调优变量表 (Tuning Variables)

> **所属 GDD**：TransparentPet | **状态**：v0.1.0-draft
> **原则**：所有数值为**假设**，未经 playtest 验证。标 `[PLACEHOLDER]` 的值需在调优中确认。

---

## 使用说明

本表汇总 GDD 全部数值假设，按系统分组。每项包含：

- **变量名**：代码/配置中的标识
- **假设值**：初始假设
- **最小/最大**：调优区间
- **调优说明**：为什么是这个值、调高/调低的影响
- **来源章节**：GDD 中首次定义的位置

**调优流程**：playtest 前 → 用假设值；playtest 后 → 根据反馈调整；确认后 → 移除 `[PLACEHOLDER]` 标记并升 GDD 版本。

## 调优优先级

playtest 时的调优顺序建议：

| 优先级 | 变量组                               | 理由                             |
| ------ | ------------------------------------ | -------------------------------- |
| P0     | 互动手感（拖拽延迟、抛射参数、形变） | 支柱 2，Moment 循环成立的基础    |
| P0     | 自主行为频率                         | 支柱 1，"打扰 vs 失存在感"临界点 |
| P1     | 情绪衰减与表现                       | 支柱 1，影响陪伴感真实性         |
| P1     | 解锁节奏                             | 支柱 3，影响留存                 |
| P2     | 自定义影响强度                       | 体验优化，非核心                 |
| P2     | 隐藏内容占比                         | 长期探索，非首版关键             |
