# 快速测试指南

## 项目结构

当前项目已精简为最简配置：

```
src/
├── config/
│   └── pet_config.gd
├── controllers/
│   ├── drag_controller.gd
│   ├── mouse_manager.gd
│   ├── settings_window.gd
│   ├── settings_window.tscn
│   └── vector_renderer.gd
├── interaction/
│   └── touch_response.gd
├── managers/
│   ├── material_manager.gd
│   └── window_manager.gd
└── pet.gd
```

## 测试步骤

### 1. 运行游戏

在Godot编辑器中运行项目，或使用命令行：

```bash
cd transparent-pet
godot --path .
```

### 2. 检查控制台输出

应该看到以下输出：
```
✅ [桌宠] ====== 桌宠主程序初始化完成 ========
[MaterialRegistry] Registered preset: 蓝色史莱姆
[MaterialManager] Applied preset: 蓝色史莱姆
✅ [配置] 配置文件加载成功: res://data/pet_config.cfg
...
```

### 3. 测试基本功能

- [ ] **拖动功能**：点击并拖动桌宠，应该能自由移动
- [ ] **鼠标穿透**：桌宠后面的内容应该可以点击
- [ ] **设置窗口**：按 `Ctrl+S` 应该打开设置窗口

## 故障排除

### 问题：材质效果不显示

**检查**：
1. 确认着色器文件路径正确：`res://assets/shaders/slime.gdshader`
2. 确认材质已正确应用
3. 检查控制台是否有错误信息

### 问题：拖动功能失效

**检查**：
1. 确认`drag_controller`正确初始化
2. 确认`pet_sprite`节点存在
3. 检查鼠标事件是否被正确捕获

### 问题：设置窗口无法打开

**检查**：
1. 确认`Ctrl+S`快捷键配置正确
2. 确认场景文件路径正确：`res://src/controllers/settings_window.tscn`
3. 检查控制台错误信息
