# 快速测试指南

## 测试步骤

### 1. 运行游戏

在Godot编辑器中运行项目，或使用命令行：

```bash
cd transparent-pet
# 编辑器模式运行
godot --path .
```

### 2. 检查控制台输出

应该看到类似以下输出：
```
✅ [Pet] 初始化完成
[MaterialManager] Applied preset: 蓝色史莱姆
✅ [Config] 配置加载成功
```

### 3. 测试基本功能

- [ ] **拖拽功能：** 点击并拖拽宠物，应该能自由移动
- [ ] **抛射功能：** 快速拖拽并松开，宠物应该被抛出
- [ ] **鼠标穿透：** 鼠标不在宠物上时，应该能点击穿透
- [ ] **设置窗口：** 按 `键（反引号）应该打开设置窗口
- [ ] **系统托盘：** 右键托盘图标，应该能打开菜单

## 故障排除

### 问题：材质效果不显示

**检查：**
1. 确认着色器文件路径正确：`res://modules/display/shaders/slime.gdshader`
2. 确认材质已正确应用
3. 检查控制台是否有错误信息

### 问题：拖拽功能失效

**检查：**
1. 确认 `interaction` 模块正确加载
2. 确认 `drag_controller.gd` 正常工作
3. 检查碰撞体配置正确

### 问题：设置窗口无法打开

**检查：**
1. 确认快捷键配置正确（`OpenSettings 输入映射
2. 确认场景文件路径正确：`res://modules/settings/ui/settings_window.tscn`
3. 检查控制台错误信息

### 问题：GDExtension加载失败

**检查：**
1. 确认已运行过 `gdextension/build.py` 编译成功
2. 确认DLL文件存在于 `addons/*/bin/` 目录
3. 确认 `.gdextension` 文件配置正确

## 项目结构确认

确认以下文件/目录存在：
- `transparent-pet/core/` - 核心系统
- `transparent-pet/modules/` - 功能模块
  - `pet/`
  - `display/`
  - `interaction/`
  - `effects/`
  - `settings/`
- `transparent-pet/prototypes/` - 原型区
- `transparent-pet/config/` - 配置文件
