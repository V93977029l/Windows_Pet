# 数据持久化架构

## 分层

```
├── ConfigManager  ← 管理配置（用户偏好、可调参数）
│   └── 每个模块一个默认文件: res://config/模块名.cfg
│   └── 用户修改集中存到: user://pet_config.cfg（或 export/pet_config.cfg 调试用）
│
└── DataManager    ← 管理数据（游戏进度、运行时状态）
    └── JSON 格式: user://data/savegame.json（或 export/savegame.json 调试用）
```

## ConfigManager

### API

| 方法 | 说明 |
|------|------|
| `load_defaults(namespace)` | 加载 `res://config/{namespace}.cfg` |
| `cfg_get(section, key, default)` | 读取：用户覆盖 > 模块默认 > 兜底值 |
| `cfg_set(section, key, value)` | 设置，跟默认相同的自动跳过不写 |
| `save_config()` | 保存用户覆盖到文件 |

### 默认配置文件

每个模块一个文件，放在 `res://config/`：

```
config/
├── pet.cfg           [pet]           scale, material
├── window.cfg        [window]        position, always_on_top, autostart
├── throw.cfg         [throw]         enabled, gravity, speeds, multiplier
├── physics.cfg       [physics]       bounce, friction, fall
├── liquid_glass.cfg  [liquid_glass]  bg, blur, tint, items
└── svg.cfg           [svg]           ratios, sizes
```

### 使用示例

```gdscript
# 1. 模块初始化时加载自己的默认配置
ConfigManager.load_defaults("pet")

# 2. 读写
var scale = ConfigManager.cfg_get("pet", "pet_scale", 1.0)
ConfigManager.cfg_set("pet", "pet_scale", 1.5)

# 3. 保存用户修改
ConfigManager.save_config()
```

### 用户配置文件

只存跟默认不同的字段，例如用户只改了缩放：

```ini
[pet]
pet_scale=1.5
```

### 路径隔离

| 模式 | 路径 |
|------|------|
| 调试（编辑器 / debug 构建） | `F:\VSCode\game\export\pet_config.cfg` |
| 发布（release 构建） | `%APPDATA%\Godot\app_userdata\TransparentPet\pet_config.cfg` |

文件名相同，路径不同，互不污染。

## DataManager

### API

| 方法 | 说明 |
|------|------|
| `save_pet_position(pos)` | 保存史莱姆关闭前位置 |
| `load_pet_position()` | 读取上次位置 |

### 路径隔离

| 模式 | 路径 |
|------|------|
| 调试 | `F:\VSCode\game\export\savegame.json` |
| 发布 | `%APPDATA%\Godot\app_userdata\TransparentPet\data\savegame.json` |

## 安全措施

- **调试/发布隔离**：路径不同，互不影响
- **只打包默认配置**：用户覆盖文件在 `export/` 或 `user://`，不在项目内
- **Data 先写临时文件**：写入 `.tmp` 成功后才替换原文件
