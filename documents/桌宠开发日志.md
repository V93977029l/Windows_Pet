# 桌宠开发日志

## 版本管理规范

### 版本号格式
- **三位版本号**：`X.Y.Z`
  - `X`：主版本号（0-∞），1.0.0为正式版
  - `Y`：次版本号（0-∞），表示大版本更新，包含重要功能或系统变更
  - `Z`：修订号（0-∞），表示小版本更新，包含Bug修复、优化和小功能

### 版本类型标记
- **开发版本**：内部开发过程中的版本，使用`DEV`标记
  - 如：`0.0.1-DEV`、`1.0.0-DEV`（正式版的开发版本）
- **发布版本**：公开发布到平台的版本，使用`RELEASE`标记
  - 如：`0.3.0-RELEASE`（发布到Steam的预览版本）、`1.0.0-RELEASE`（正式版的发布版本）

### 记录格式
- **开发版本**：记录开发日期、开发内容
- **发布版本**：记录开发日期、发布日期、发布内容、平台信息
- **大版本更新**：添加`## 大版本更新说明`部分，详细说明重要变更

## 大版本更新说明

### 一、桌宠角色

史莱姆形态的桌面宠物，以无边框透明窗口悬浮于桌面之上。

- **窗口特性**：无边框、透明背景、始终置顶（可开关）、不可调整大小、启动时自动居中
- **拖动交互**：鼠标左键按住角色即可自由拖动到桌面任意位置
- **窗口重启记忆**：关闭后重新打开，窗口自动恢复到上次的位置

### 二、像素级鼠标穿透

当鼠标不在角色上时，窗口自动穿透所有点击事件，完全不干扰桌面正常操作。当鼠标悬停在角色上时，穿透关闭，可以正常交互。

- 基于 alpha 通道的逐像素精确检测，非矩形包围盒
- 同时支持 `Sprite2D` 像素检测和 `Polygon2D` 多边形检测两种方式
- 底层通过 GDExtension 调用 Windows `WS_EX_TRANSPARENT` / `WS_EX_LAYERED` 实现
- 任务栏图标通过 `WS_EX_TOOLWINDOW` 隐藏，桌宠不占用任务栏空间

### 三、系统托盘

最小化到 Windows 系统托盘，常驻后台，不干扰工作。

- **左键点击托盘图标**：打开设置窗口
- **右键点击托盘图标**：弹出菜单（设置 / 退出）
- **explorer 重启恢复**：监听 `TaskbarCreated` 消息，资源管理器重启后自动重建托盘图标
- 启动时自动隐藏任务栏图标，仅保留托盘图标

### 四、设置窗口

`` ` `` 键（反引号）或左键点击托盘图标打开设置面板，所有修改即时生效。

- **缩放控制**：滑块 + 数值输入框双向绑定，范围 0.2× ~ 4.0×，配有"确定"按钮精确应用
- **材质切换**：下拉菜单选择预设 ShaderMaterial，当前内置"可爱史莱姆"蓝色材质
- **动态效果开关**：控制史莱姆着色器的顶点波动动画（液体晃动效果），可独立开关
- **窗口置顶开关**：控制桌宠是否始终显示在所有窗口之上
- **保存配置**：将当前设置写入 `pet_config.cfg` 持久化
- **恢复默认**：一键恢复所有配置项为出厂默认值

### 五、史莱姆着色器效果

基于 `canvas_item` 的自定义 ShaderMaterial，呈现类似玻璃/凝胶的史莱姆质感。

- **顶点动画**：基于噪声的顶点波动，模拟液体晃动（通过"动态效果"开关控制）
- **分形噪声**：4 阶 FBM（分形布朗运动）驱动片元阶段的动态扭曲
- **菲涅尔边缘光**：边缘发光效果，可配置菲涅尔强度
- **高光泽高光**：镜面反射般的高光点，增强质感
- **透明渐变**：透明度由边缘向中心递减

### 六、矢量渲染

角色使用 SVG 矢量资源，支持任意缩放不失真。

- 资源以 SVG 文件存储（`pet_sprite.svg`），Godot 导入为 `ImageTexture`
- 缩放时对 SVG 重新渲染为更高分辨率位图（2× 超采样），避免放大模糊
- 与材质系统解耦，渲染管线独立

### 七、项目基础信息

- **引擎**：Godot 4（渲染驱动 Direct3D 12）
- **物理引擎**：Jolt Physics
- **扩展**：GDExtension（C++），两个核心插件 —— `MousePassthrough`（鼠标穿透 + 任务栏隐藏）、`SystemTray`（系统托盘）
- **扩展编译**：Python 一键编译脚本 `build.py`，自动编译 godot-cpp + 所有扩展并部署到 `addons/`
- **外部依赖**：`godot-cpp`（Godot 官方 C++ 绑定，Git Submodule 管理，跟随 master 分支）
- **源码结构**：`src/` 目录下 8 个 GDScript 模块 —— `pet.gd`（主协调器）、`drag_controller.gd`（拖动）、`mouse_manager.gd`（鼠标检测）、`material_manager.gd`（材质管理）、`vector_renderer.gd`（SVG 矢量渲染）、`tray_manager.gd`（托盘接口）、`settings_window.gd`（设置窗口逻辑）、`pet_config.gd`（配置持久化）

### 附：液态玻璃演示（实验性功能，未包含在内测发行包中）

独立于桌宠主程序的实验性场景（`liquid_glass_demo/`），展示多形状可拖拽液态玻璃效果。包含完整的 SDF 形状系统（圆形、超椭圆角矩形、史莱姆形）、折射/色散/菲涅尔/眩光光学模拟、双通道高斯模糊背景。此功能参考开源项目 `liquid-glass-studio` 的 WebGL 实现，作为后续效果的预研，本次内测版本不包含此演示。
