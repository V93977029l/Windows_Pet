# TransparentPet 项目结构总览

这是一个 **Godot 4 桌面桌宠（Desktop Pet）项目**，名为 **TransparentPet**。核心功能是：一个小型桌面精灵角色，具有透明背景、鼠标穿透（仅在鼠标悬停时交互）、系统托盘控制等功能。项目使用 **GDExtension**（C++ 原生扩展）与 Windows API 进行底层交互。此外还包含一个独立的 **液态玻璃效果** (liquid-glass) 实验性子项目（参考了开源项目 liquid-glass-studio 的 WebGL 实现）。

## 二、`transparent-pet/src/` 目录 -- 核心 GDScript 源码

这是主要业务逻辑所在，共 **8 个 `.gd` 文件**：

### 1. [pet.gd](file:///f:/VSCode/game/transparent-pet/src/pet.gd) -- 桌宠主节点
- **类型**: `Node2D`
- **功能**: 桌宠的入口节点，负责协调所有子系统。
  - `_ready()`: 初始化矢量渲染器、材质管理器、拖动控制器、鼠标穿透管理器、系统托盘管理器
  - 处理精灵定位（居中/记住上次位置）、缩放
  - `_process()`: 每帧更新拖动和鼠标穿透状态
  - 监听 `OpenSettings` 输入事件（快捷键 `` ` `` 键）打开设置窗口
  - 监听系统托盘的 `settings_requested` 和 `exit_requested` 信号
  - 通过 `center_sprite()` 在启动时将精灵放在屏幕中央或上次保存的位置

### 2. [settings_window.gd](file:///f:/VSCode/game/transparent-pet/src/settings_window.gd) -- 设置窗口逻辑
- **类型**: `Window`（Godot 独立子窗口）
- **功能**: 设置窗口的完整交互逻辑。
  - 缩放控制：HSlider + LineEdit 双向绑定（范围 0.2-4.0），"确定"按钮应用缩放
  - 材质类型：OptionButton 下拉选择预设材质
  - 动态效果：CheckButton 启用/禁用液态流动效果
  - 窗口置顶：CheckButton 切换 always_on_top
  - 保存/恢复默认配置按钮
  - 窗口关闭时 `queue_free()` 销毁自身

### 3. [pet_config.gd](file:///f:/VSCode/game/transparent-pet/src/pet_config.gd) -- 配置管理
- **类型**: `RefCounted`
- **功能**: 使用 Godot 内置 `ConfigFile` API 管理持久化配置。
  - 配置项：`pet.scale`（缩放）、`pet.material_preset`（材质预设）、`window.initial_x`/`window.initial_y`（窗口位置）、`window.always_on_top`（置顶）
  - 配置文件路径：`res://data/pet_config.cfg`
  - 启动时自动加载，配置缺失时创建默认值并保存

### 4. [drag_controller.gd](file:///f:/VSCode/game/transparent-pet/src/drag_controller.gd) -- 拖拽控制器
- **类型**: `RefCounted`
- **功能**: 实现精灵的鼠标拖拽功能。
  - 在 `MOUSE_BUTTON_LEFT` 按下时记录点击偏移量
  - `update_drag()` 每帧更新精灵位置以跟随鼠标
  - 在 `_on_area_2d_input_event` 中触发（通过 CollisionShape2D 检测碰撞）

### 5. [mouse_manager.gd](file:///f:/VSCode/game/transparent-pet/src/mouse_manager.gd) -- 鼠标检测管理器
- **类型**: `RefCounted`
- **功能**: 检测鼠标是否悬停在精灵的不透明像素上。
  - `is_mouse_over_sprite()`: 对 `Sprite2D` 类型逐像素检测 alpha 通道；对 `Polygon2D` 类型用多边形包围盒检测
  - `update_mouse_passthrough()`: 每帧根据鼠标位置调用 `passthrough_manager.update_mouse_passthrough()`

### 6. [material_manager.gd](file:///f:/VSCode/game/transparent-pet/src/material_manager.gd) -- 材质管理器
- **类型**: `RefCounted`
- **功能**: 管理精灵的 ShaderMaterial 预设系统。
  - 内嵌 `MaterialPreset` 类（id、name、description、parameters）
  - 内嵌 `MaterialRegistry` 类（注册/查询预设）
  - `apply_preset()`: 加载 shader（`slime.gdshader`）并创建 `ShaderMaterial` 应用到精灵
  - `set_dynamic_enabled()`: 控制 shader 的 `enable_dynamic` 参数
  - 默认预设："可爱史莱姆"（blue_slime）

### 7. [vector_renderer.gd](file:///f:/VSCode/game/transparent-pet/src/vector_renderer.gd) -- 矢量渲染器
- **类型**: `RefCounted`
- **功能**: 加载 SVG 矢量精灵并支持高分辨率缩放重渲染。
  - `init()`: 加载 SVG 文件内容，设置精灵纹理
  - `update_scale()`: 简单缩放精灵节点
  - `apply_high_res_scale()`: 通过 `Image.load_svg_from_string()` 重新渲染 SVG 为更高分辨率的位图纹理（x2 缩放因子），避免模糊

### 8. [tray_manager.gd](file:///f:/VSCode/game/transparent-pet/src/tray_manager.gd) -- 系统托盘管理器
- **类型**: `Node`
- **功能**: 封装 GDExtension SystemTray 的 GDScript 接口。
  - 检测 `ClassDB.class_exists("SystemTray")` 并尝试手动加载 `.gdextension` 文件
  - 创建托盘图标（标题 "TransparentPet"，提示 "桌宠"）
  - 左键点击触发 `settings_requested` 信号（打开设置窗口）
  - 右键菜单触发 `exit_requested` 信号（退出应用、弹出退出菜单）
  - 隐藏任务栏图标：通过 `hide_taskbar_icon()` 实现

### 9. [main.gd](file:///f:/VSCode/game/transparent-pet/liquid_glass_demo/main.gd) -- 液态玻璃演示主场景逻辑
- **类型**: `Node2D`
- **功能**: 液态玻璃演示场景的交互控制。
  - 处理鼠标拖拽 GlassItem 对象
  - 空格键切换控制面板的可见性
  - 将鼠标位置传递给 LiquidGlassRenderer

## 四、着色器文件 (`.gdshader`)

### 1. [slime.gdshader](file:///f:/VSCode/game/transparent-pet/assets/shaders/slime.gdshader) -- 史莱姆着色器
- **类型**: `canvas_item`（2D shader）
- **功能**: 为桌宠精灵提供类似玻璃/史莱姆的视觉效果。
  - `vertex()`: 基于噪声实现顶点波动动画（`enable_dynamic` 控制）
  - `fragment()`:
    - 4 阶 FBM（分形布朗运动）噪声用于动态扭曲
    - 菲涅尔边缘光效果（`fresnel_power`）
    - 高光泽高光（Specular）
    - 透明度随到中心距离渐变
  - 参数：`glass_color`、`edge_glow`、`highlight_intensity`、`liquid_wobble`、`wobble_speed`、`fresnel_power`、`enable_dynamic`

### 2. [liquid_glass_main.gdshader](file:///f:/VSCode/game/transparent-pet/liquid_glass_demo/shaders/liquid_glass_main.gdshader) -- 液态玻璃主着色器
- **功能**: 实现完整的液态玻璃视觉效果。
  - 最多 3 个形状的 SDF（圆形、超椭圆圆角矩形、史莱姆形）
  - 形状间通过 `smin()` 平滑混合（`u_mergeRate` 控制合并率）
  - 折射计算：使用 Snell 定律模拟光线折射
  - 色散：RGB 通道分离偏移
  - 菲涅尔效果：边缘反射增强
  - 眩光（Glare）：角度相关的高光
  - 色彩空间转换：sRGB -> XYZ -> Lab -> LCH 用于高质量颜色计算
  - 抗锯齿：基于 SDF 梯度

### 3. [liquid_glass_bg.gdshader](file:///f:/VSCode/game/transparent-pet/liquid_glass_demo/shaders/liquid_glass_bg.gdshader) -- 背景着色器
- **功能**: 渲染液态玻璃的背景层，支持多种背景类型（纯色、纹理、视频等）

### 4. [liquid_glass_blur.gdshader](file:///f:/VSCode/game/transparent-pet/liquid_glass_demo/shaders/liquid_glass_blur.gdshader) -- 模糊着色器
- **功能**: 双通道高斯模糊（垂直+水平），用于玻璃背景的模糊效果

### 5. [sdf_utils.inc](file:///f:/VSCode/game/transparent-pet/liquid_glass_demo/shaders/sdf_utils.inc) -- SDF 工具函数
- **功能**: 可复用的 SDF 工具函数头文件。
  - `sdCircle()`: 圆形 SDF
  - `superellipseCornerSDF()`: 超椭圆角 SDF
  - `roundedRectSDF()`: 圆角矩形 SDF
  - `smin()`: 平滑最小值（形状混合）
  - `sdSlime()`: 史莱姆形状 SDF（由多个圆形平滑混合组成）
